# SWAN 웹사이트

사내 SW 교육 SWAN(SW Academy for Newbie)과 이를 운영하는 Design Technology팀 IPS 파트를 알리고, 교육 신청을 받는 사내 웹사이트. 교육은 파이썬 초급 딱지를 막 뗀 현업 엔지니어가 Python 중고급과 바이브코딩 노하우를 배우는 주 1회 온라인 3개월 과정이다.

## 누구를 위한 사이트인가
- **예비 수강생**: 파이썬은 쓸 줄 알지만 AI가 짠 코드가 맞는지 판단할 눈이 없는 현업 엔지니어 — 핵심 행동: 완성작과 커리큘럼을 보고, 수준 테스트를 풀어 보고(선택), 신청한다
- **졸업생**: 역대 수료생 — 완성작을 올리고, 토이프로젝트 팀원을 모은다
- **수강생**: 현재 기수 신청자 — 토이프로젝트에 참여한다
- **실무진**: 교육과 무관한 사내 직원 누구나 — 아이디어 보드에 가벼운 개발 요청을 남기고 공감한다
- **보는 사람**: 팀장급 — 성과와 완성작을 보고 팀원을 보낼지 판단한다 (보기만)
- **관리자**: 운영자와 부장님 (추가될 수 있음) — 기수, 신청자, 승인, 아이디어, 문제, 커리큘럼 관리

## 핵심 루프
메일·사내 게시판의 [신청하기] → 홈 첫 화면 맨 위(자동 로그인) → 스크롤하며 완성작·강사·커리큘럼 확인 → 수준 테스트(선택) → 신청 → 접수 완료

판단이 애매하면 이 기준으로 정한다: **망설이던 사람이 눈으로 보는 증거로 확신을 얻어 그 자리에서 신청하게 되는가.**

## 범위
- 이번에 만든다: 홈(10개 섹션), 완성작 갤러리·상세·올리기·승인·좋아요, 수준 테스트(6문제), 신청과 취소, 다음 기수 알림 받기, 토이프로젝트, 아이디어 보드, 제작 과정 화면, 관리자 화면, 임시 로그인, 방문·섹션 도달·클릭 기록
- 임시로 처리: SSO(→ 테스트 사용자 고르기), 모든 데이터(가상), 실습 프로젝트의 미리보기 그림·영상(자리 그림)
- 만들지 않는다: 통계 화면, 갤러리 댓글, 메일·메신저 알림 발송, 모바일 화면

## 기술
- PC 전용 웹. 사내망에서 쓴다
- 화면: React + Vite + TypeScript + Tailwind CSS / 움직임: GSAP ScrollTrigger / 3D: three.js(react-three-fiber)를 한두 곳에만 (홈 인트로의 오리·백조, 접수 완료) / 편집기: Toast UI Editor
- 서버: Python FastAPI / DB: SQLite(SQLAlchemy) / 파일: 서버 로컬 폴더
- 배포: 화면을 빌드해 FastAPI가 함께 서비스하는 한 덩어리
- **외부 연결 금지**: 글꼴, 라이브러리, 이미지, 영상을 모두 사이트에 포함한다. CDN과 외부 글꼴 링크를 쓰지 않는다
- 인증은 한곳(`auth` 모듈)에 모아, 임시 로그인을 나중에 SSO로 바꿀 수 있게 한다

### 데이터 모델
- User(사번, 이름, 부서, SSO 아이디, 관리자 여부)
- Cohort(기수 번호, 모집 시작·종료일, 개강·종료일, 강의 요일·시간, 모집 상태) — 모집 중은 최대 1개
- Application(사용자, 기수, 파이썬 경험, 만들고 싶은 것, 신청·취소 시각, 수료 여부) — 사용자·기수당 유효한 신청 1건
- Alumni(이름, 부서, 기수, 사번) — 엑셀로 올린 역대 명단. 사번으로 User와 이어진다
- Interest(사용자, 등록 시각) — 다음 기수 알림
- Project(작성자, 제목, 짧은 설명, 대표 이미지, 문제, 효과, 화면 캡처들, 발표자료, 저장소 주소, 자세한 설명, 상태, 반려 이유) / ProjectLike(사용자, 완성작)
- QuizQuestion(순서, 유형: 보기 고르기/주관식/줄 고르기, 제목, 상황 설명, 코드, 질문, 보기, 정답, 부분 정답 줄, 해설, 더 나은 코드, 줄 옆 설명) / QuizAttempt(사용자, 시각, 맞힌 개수, 문제별 답, 첫 응시 여부)
- Idea(작성자, 제목, 설명, 이름 표시 방식, 상태, 파트 답변, 숨김) / IdeaVote(사용자, 아이디어)
- ToyPost(작성자, 제목, 만들 것, 필요한 역할·인원, 예상 기간, 모집 상태, 숨김) / ToyJoin(사용자, 모집 글)
- CurriculumUnit(순서, 단계, 제목, 배우는 것) / PracticeProject(순서, 제목, 한 줄 설명, 세부 내용, 주제 묶음, 기르는 힘, 미리보기 그림, 미리보기 영상)
- EventLog(사용자, 종류: 방문/섹션 도달/클릭, 대상, 시각)

### 권한
| 유형 | 판별 | 할 수 있는 것 |
|---|---|---|
| 로그인 실패 | 인증 실패 | 모든 화면 보기만. 버튼을 누르면 "로그인이 필요해요" |
| 직원 | 인증 성공 | 신청·취소, 수준 테스트, 좋아요, 아이디어 남기기·공감, 다음 기수 알림 |
| 수강생 | 현재 기수 신청자 | + 토이프로젝트 글쓰기·참여 |
| 졸업생 | Alumni에 있음 | + 완성작 올리기·수정, 토이프로젝트 글쓰기·참여 |
| 관리자 | 관리자 여부 | + 관리자 화면 전체 |

## 꼭 지킬 동작 규칙
- 들어오면 자동으로 로그인된다. 로그인 버튼이 없다. 실패해도 열람은 된다
- 상단 오른쪽 버튼은 상태에 따라 바뀐다: [신청하기] / [신청 완료](누르면 "신청을 취소할까요?") / [다음 기수 알림 받기](모집 기간이 아닐 때)
- 선발이 없다. 신청하면 수강 확정이다
- 신청서는 두 칸뿐이다: 파이썬 경험(선택형), 만들고 싶은 것(선택). 이름·부서·사번은 화면에 보여주지 않고 뒤에서 저장한다
- 수준 테스트는 6문제(객관식 4, 주관식 1, AI 코드에서 틀린 줄 클릭 1)이고 내용은 `planning/v3-1013/level-test.md`를 쓴다. 선택 사항이고, 어떤 결과가 나와도 신청을 막지 않는다. 결과는 합격·불합격이 아니라 성장 단계(알에서 나온 오리 / 아기 오리 / 어린 백조)로 보여준다. 다시 풀 수 있지만 첫 결과를 기준 기록으로 남긴다
- 완성작은 관리자 승인 후 공개된다. 토이프로젝트 글과 아이디어는 올리면 바로 공개되고 관리자가 숨길 수 있다
- 좋아요와 공감은 한 사람이 한 번이다
- 완성작에는 만든 사람의 이름, 부서, 기수를 모두 표시한다. 아이디어는 쓰는 사람이 이름 표시 방식을 고른다
- 방문, 섹션 도달, 주요 버튼 클릭을 처음부터 기록한다

## 커리큘럼
- 내용은 `planning/v3-1013/curriculum.md`를 그대로 쓴다 (실제 4기 자료). 주차표가 아니라 **이론 5단원 + 실습 프로젝트 11개 + 바이브코딩 단원(5기 신설)**이다
- 사이트에서는 "배우는 흐름 4단계(다지기 → 깊어지기 → 만들기 → AI와 함께 만들기)"와 "실습 프로젝트 모음"으로 보여준다. 프로젝트 모음이 중심이고, 프로젝트마다 미리보기 그림이나 영상이 있다
- 4단계 "AI와 함께 만들기"는 5기에 새로 생기는 바이브코딩 단원이다. `curriculum.md` 3부의 단원 구성을 쓰고, 화면에 "5기 신설" 표시를 붙인다. 특정 도구 이름을 앞세우지 않는다 (도구와 무관한 원칙 중심). 3부에 없는 단원을 지어내지 않는다

## 디자인 원칙
- 디자인 방향은 **A 개발자의 노트**로 정했다 (2026-10-16). 미색 종이, 줄 번호, `//` 주석, 하늘색 형광펜. 값과 부품 상태, 움직임 표는 `SWAN/design/direction-a/구현-전달.md`를 그대로 쓴다. 값은 한곳(Tailwind 테마)에 모은다
  - 색: paper `#fbfaf7` / ink `#1f2a44` / sky `#d6ecfb` / line `#dfe3ea` / ink-muted `#5b6273` / mark `#7d93b0`. 화면 요소에 노랑을 쓰지 않는다 (캐릭터 색은 예외)
  - 글꼴: 제목 NanumSquareRound 800 · 본문 Pretendard · 줄 번호와 주석 JetBrains Mono. 글꼴 파일은 사이트에 포함한다
  - 캐릭터: 안경을 쓰고 노트북을 든 매끈한 3D 오리(수강생)와 강사 백조(남색 니트 조끼 + 흰 셔츠 깃). 뼈대와 움직임(`idle` 숨쉬기 · `wave` 손 흔들기 · `tilt` 갸웃 · `hop` 뛰기)이 들어 있다. 파일 `SWAN/design/3d/duckling-v2/duckling-v2-rigged.glb`, `SWAN/design/3d/instructor/instructor-rigged.glb`. 첫 화면 배치 기준 `SWAN/design/hero-3d/hero-a.png`
  - 수준 테스트 성장 단계는 3D 정지 그림 `SWAN/design/stages-3d/` (알에서 나온 오리 / 아기 오리 / 어린 백조). 어린 백조는 조끼 없는 백조라 강사와 구분된다
  - 3D를 쓸 수 없거나 움직임 줄이기 설정이면 같은 자세의 정지 그림(`SWAN/design/hero-3d/*-c.png`)을 보여준다
- 메인 문구: "날개는 AI가 달아 줍니다. 나는 법은 여기서 배웁니다." / 서브(잠정): "AI 시대, SW를 보는 눈을 기릅니다."
- 하지 말 것: 그라디언트, 빛 번짐, 반투명 유리 카드, 똑같은 카드 줄의 반복, 모든 것을 가운데 정렬, 제목 위의 작은 영어 대문자 라벨, 이모지 아이콘
- UX: 고르는 방식 우선, 타이핑은 최소로. 저장하면 화면 구석에 짧은 확인. 되돌릴 수 없는 일(신청 취소, 삭제)은 한 번 더 묻는다

## 작업 방식
- `planning/v3-1013/claude-code-prompt.md`의 Phase 단위로 진행하고, 끝나면 무엇을 만들었는지와 확인하는 방법을 요약한다
- 기획에 없는 기능을 임의로 추가하지 않는다. 필요하면 먼저 묻는다
- 화면 문구는 한국어로 쓴다
- **실제 사내 정보를 넣지 않는다.** 이름, 사번, 완성작은 모두 가상으로 만들고 코드 주석에 가상이라고 적는다
- AI가 틀린 결과를 냈고 사람이 바로잡은 일이 생기면 `planning/v3-1013/build-log.md`에 세 줄로 남긴다 (무엇이 틀렸나 / 무엇을 보고 알았나 / 어떻게 고쳤나). 제작 과정 화면의 재료다
