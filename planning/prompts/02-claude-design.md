# Claude Design 프롬프트 — SWAN 홍보 사이트 시안

사용법
1. Claude Design에서 새 디자인을 열고, 아래 **첨부할 파일**을 올린다.
2. **프롬프트 1**을 붙여넣어 전체 시안을 받는다.
3. 마음에 들 때까지 **프롬프트 2~4**(수정용)로 다듬는다.
4. 확정되면 시안 스크린샷(데스크톱·모바일)을 `SWAN/design/`에 저장 → 코드 구현 Phase 3에 "이 시안대로"라고 함께 넣는다.

## 첨부할 파일 (`SWAN/` 폴더)
- `4f8444d8-....png` — 날개 편 백조 + 달빛 호수 (히어로 분위기)
- `hf_..._083350_....png` — 캐릭터 없는 달빛 호수 배경
- `hf_..._083952_....png` — 캐릭터 정면 (날개 접음)
- `hf_..._085527_....png` — 캐릭터 떠 있는 포즈 (그린 스크린)

## 프롬프트 1 — 전체 시안

사내 파이썬 교육 프로그램 **SWAN**(SW Academy for Newbie)을 홍보하는 원페이지 웹사이트를 디자인해 줘. 데스크톱(1440폭)과 모바일(390폭) 둘 다.

**목적과 독자**
- 코딩이 처음인 30~40대 사무직 현업(영업관리·품질·구매 등 엑셀 중심)이 사내 메일 링크로 들어온다. 첫 5초 안에 흥미를 느끼고 끝까지 스크롤해야 한다.
- 우선순위: ① SWAN과 운영 부서(**Design Technology팀 IPS 파트**)를 알리는 홍보 ② 5기 수강신청 ③ 실무진의 가벼운 개발 아이디어 접수
- "사내 사이트 같지 않은" 프리미엄·다이나믹한 퀄리티. 레퍼런스: soijeong.com (섹션을 넘나드는 마스코트, 화면보다 큰 키네틱 타이포, 섹션마다 배경색이 통째로 바뀌는 장면 전환)

**무드: 달빛 호수의 밤** (첨부 이미지 참고)
- 색: night `#0b1424`(바탕) / deep `#13213a`(카드) / mist `#c9d6ea`(본문) / moon `#f3ead2`(제목·주요 버튼) / glow `#7fe3e6`(노트북 화면 시안, 강조) / amber `#e8b36a`(금빛 안개, 보조 포인트)
- 폰트: 제목 Gowun Batang(서정적 명조) / 본문 IBM Plex Sans KR / 라벨·숫자·코드 JetBrains Mono
- 마스코트: 첨부한 안경 쓴 후드티 백조. 사이트 전체를 안내하는 가이드로, **SWAN 소개 카드 · IPS 파트 소개 카드 · 마지막 CTA** 세 곳에 앉아 있다 (카드 안에 마스코트가 앉을 자리를 디자인에 포함)
- 섹션이 내려갈수록 호수의 시간대가 바뀐다: 달밤 → 새벽 푸른 안개 → 금빛 안개 → 다시 달밤

**섹션 (위 → 아래)**
1. **상단 내비**: SWAN 로고, 섹션 바로가기, 우측 고정 [5기 신청] 버튼 (반투명 블러)
2. **히어로/인트로**: 첨부한 날개 편 백조 + 달빛 호수 전면. eyebrow `SW Academy for Newbie`, 제목 **처음이어도, 우아하게.**, 서브카피 **3개월 뒤, 매일 하던 반복 업무가 Python으로 가벼워집니다.**(제목 아래 작게, 본문 폰트), 하단 `SCROLL ↓`
3. **SWAN 소개 카드 패널**: 소제목 `SWAN · 5기 모집`, 제목 **물 위에선 우아하게, 물 밑에선 열심히 코딩하기**. 카드: 마스코트 자리 + "안녕, 나는 SWAN이야" + 설명 + 코드 한 줄 `$ python merge_reports.py ./팀별실적` → `✓ 5개 팀 실적 취합 완료 (1시간 30분 → 4초)`. 칩 3개: 환경 세팅부터 같이 / 결과물 부담 없이 / AI 활용법까지
4. **성과 숫자**: 4개 기수 · 누적 졸업생 36명 · 만든 자동화 40개 · 3개월 과정 (큰 모노 숫자)
5. **키네틱 타이포 띠**: 화면보다 큰 글자 두 줄이 반대 방향으로 흐름 — `Python for Newbie · 처음이어도, 우아하게 ·` / `물 밑에선 열심히 · Automate the boring stuff ·`
6. **커리큘럼**: "주 2~3회 · 회당 2시간 · 오프라인 · 3개월". 세로 진행선 타임라인 4단계
   - 1~2주 물에 발 담그기: 사내 환경 세팅, 파이썬 기초, AI 코딩 도우미
   - 3~5주 데이터와 친해지기: 엑셀·CSV, pandas, 파일 자동화
   - 6~8주 자동화 날개 달기: 보고서 자동 생성, 메일·웹 자동화, 예약 실행
   - 9~12주 내 업무로 날아오르기: 개인 프로젝트, 멘토링, 데모데이
   각 단계 끝에 "이 단계가 끝나면 할 수 있는 것" 한 줄
7. **졸업생 쇼케이스** (새벽 안개 배경): 가로 스크롤 카드 갤러리. 카드 = 직무·기수 배지, 결과물 제목, **Before → After 시간** 크게, 기술 태그. 예: "실적 자동 취합기 · 3기 · 영업관리 · 1시간 30분 → 4초". 데이터가 없을 때의 빈 상태 카드("곧 졸업생들의 작품이 걸립니다")도 한 장
8. **IPS 파트 소개** (금빛 안개 배경): "Design Technology팀 IPS 파트 — 현업에 필요한 웹과 툴을 만듭니다". 하는 일 키워드 태그가 흐르는 띠(업무 자동화 · 사내 웹 시스템 · 데이터 대시보드 · 보고서 자동화 · SWAN 교육). 마스코트가 앉은 소개 카드 + 말풍선 "필요한 툴, 우리가 만들어 드려요"
9. **아이디어 보드**: "부서장님께 말하긴 애매한 작은 불편, 여기 던져 주세요". 살짝 기울어진 포스트잇 카드 더미 — 제목, 부서, 상태 배지(검토 중/개발 중/완료), [👍 나도 필요해요 12] 버튼. [아이디어 남기기] 버튼과 그 모달(제목, 설명, 공개 여부 토글)
10. **토이프로젝트**: "졸업생 전용" 배지, 모집 카드 3개 (리더 기수, 모집 인원 진행 막대, 기술 태그)
11. **마지막 CTA + 푸터**: 큰 달 글로우 위에 날개를 펴고 날아오르는 마스코트, **다음 호수에서 만나요 — SWAN 5기**, [5기 신청] / [아이디어 남기기]. 푸터: Design Technology팀 IPS 파트 · 문의처

**규칙**
- 주요 버튼은 moon 색 알약형, 보조는 glow 외곽선
- 텍스트 대비 충분히 (본문 mist on night)
- 모바일: 모든 카드 1열, 가로 스크롤은 스와이프, 마스코트가 본문을 가리지 않게
- 정보는 짧고 굵게. 팝업 배너·뉴스레터·FAQ 같은 군더더기 금지

## 프롬프트 2 — 역동성 강화 (시안이 얌전할 때)
더 다이나믹하게 해 줘. soijeong.com처럼 섹션 제목을 화면 폭에 가깝게 키우고, 섹션 사이 배경 전환을 더 극적으로(달밤 → 푸른 안개 → 금빛) 보여줘. 카드끼리 겹치거나 기울어진 레이어를 더 써도 좋아. 각 섹션에서 스크롤할 때 무엇이 움직이는지 화살표·주석으로 표시해 줘.

## 프롬프트 3 — 마스코트 동선 표시
마스코트가 인트로 → SWAN 소개 카드 → IPS 파트 카드 → 마지막 CTA로 이동하는 동선을 전체 페이지 위에 점선 경로로 표시한 설명용 화면을 하나 더 만들어 줘. 각 정거장에서의 포즈(날개 편 / 접은)와 크기도 표기.
