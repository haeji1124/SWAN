- AI가 짜 준 코드, 볼 줄 아는 사람이 됩니다.
- AI 시대, SW를 보는 눈을 기릅니다. (→ 서브 문구 후보로 이동)
- 코드는 AI가 짭니다. 판단은 당신이 합니다.
- AI의 답이 맞는지, 이제 당신이 압니다.

### ② 변화를 앞세운 것
- 시키는 사람에서, 판단하는 사람으로.
- 따라 치던 코드에서, 읽어 내는 코드로.
- 돌아가기만 하던 코드에서, 다시 쓸 수 있는 코드로.
- 초급 딱지를 뗐다면, 이제 고급으로.

### ③ 아이디어 구현을 앞세운 것
- 떠올린 아이디어, 직접 만들어 냅니다.
- 머릿속 아이디어가 돌아가는 프로그램이 될 때까지.
- 우리 부서에 필요한 SW, 우리가 만듭니다.

### ④ 백조 이름을 살린 것
- ✅ **날개는 AI가 달아 줍니다. 나는 법은 여기서 배웁니다.** (2026-10-14 선택)
- 물 위는 AI에게, 물 밑은 내 실력으로.
- 아기 오리는 3개월 뒤 날개를 폅니다.

### ⑤ 짧고 선언적인 것
- AI를 쓰는 사람, AI를 아는 사람.
- 보는 눈이 실력입니다.

## 서브 문구
### 취지를 말하는 것
- ✅ **AI 시대, SW를 보는 눈을 기릅니다.** (2026-10-14 사용자 제안, 잠정)
- AI가 짠 코드를 읽고, 고치고, 판단하는 힘을 기릅니다.
- AI 시대에 SW를 볼 줄 아는 실무 인력을 기릅니다.
- 코드는 AI가 짭니다. 판단은 당신이 합니다.

### 대상과 과정을 알려 주는 것
- 초급 딱지를 뗀 당신이 고급까지. Python 중고급과 바이브코딩 3개월 과정.
- Python 중고급부터 바이브코딩까지, 주 1회 3개월.
- 파이썬은 쓸 줄 아는데 AI로 만드는 건 막힌다면.
- 본업을 하면서, 우리 부서에 필요한 SW를 직접 만드는 사람이 됩니다.

### 차별점을 알려 주는 것
- 사내 환경을 아는 사내 강사가 가르칩니다.
- 막히면 물어볼 사람이 생깁니다.
- 주 3~4시간, 본업과 함께.
