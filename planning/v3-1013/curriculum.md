## 2부. 실습 프로젝트 (4기에서 진행한 것)

### 1. Fourier Series 응용: 임의의 도형 그리기
- SVG 파일 파서 작성
- Fourier series의 이해와 파이썬 구현
- matplotlib을 활용한 애니메이션 프로그램 제작 (진도에 따라 OpenGL로 확장 가능)
  - 회전하는 모든 화살표를 연결해 끝점의 경로를 애니메이션으로 표현
  - 파란색(N개, 반시계 방향)과 빨간색(N개, 시계 방향) 화살표가 정수배의 주기로 일정한 속도로 회전 (1배, 2배, …, N배 빠르기)
  - 각 화살표의 초기 크기와 방향을 Fourier series로 계산

### 2. 테트리스 제작
- pygame 패키지를 활용한 테트리스 제작
- 일반 파이썬 교육에서 배우는 리스트, 딕셔너리 등 데이터 구조를 직접 다뤄 보는 심화 예제
- 단계별 구현에 따른 코드 복잡도 경험
- 녹화 / 리플레이 기능 구현
- MVP 아키텍처 적용을 통한 코드 복잡도 조절 (GUI / Text 버전) → 아키텍처의 필요성을 체감

### 3. Equation parser 제작
- 덧셈, 곱셈, 뺄셈, 나눗셈, 괄호, 정수, 실수에 대한 수식 파싱과 계산
- 재귀 함수의 종합 실습
- 심화: JSON 포맷의 파일을 읽어 리스트, 딕셔너리로 변환하는 프로그램 제작

### 4. 미로찾기 solver 제작
- 파이썬을 활용한 미로찾기 알고리즘 제작
  - 텍스트 입력을 내부 데이터 구조로 변환
  - 최적 경로를 찾는 알고리즘 개발
  - 큐를 활용한 BFS 알고리즘 구현
  - 찾은 경로를 화면에 출력
- 입력: 미로 정보가 저장된 텍스트 파일
- 출력: 출구까지의 최단 경로
- 결과 확인을 위한 GUI 프로그램과 연동

### 5. Eight puzzle solver 제작
- 파이썬을 활용한 8 퍼즐 해결 알고리즘 제작. 문제 해결을 위한 데이터 구조 구성, 최소의 움직임으로 답을 찾는 알고리즘 제작
- 입력: 8개 버튼의 위치 (직접 입력하거나 GUI 프로그램으로 입력)
- 출력: 정답까지 최소의 버튼 움직임 (텍스트 화면과 GUI 프로그램에서 버튼 움직임 확인)
- 결과 확인을 위한 GUI 프로그램과 연동

### 6. Bird simulator
- MVP 아키텍처 심화 과제
- 새의 움직임을 계산하는 알고리즘 작성
- 각종 파라미터 값으로 움직임 제어
- pygame 패키지 사용
- 기능 추가에 따른 코드 복잡도 제어

### 7. 2048 게임 만들기
- MVP 아키텍처 심화 과정
- 2048 게임 규칙을 파이썬으로 구현
  - 숫자 블록은 상하좌우로 움직인다
  - 같은 숫자끼리 합쳐진다
  - 빈 공간으로 움직일 수 있다
  - 움직인 뒤 빈 공간에 새 블록이 생긴다
  - 더 움직일 수 없으면 게임이 끝난다
- 게임 내부 데이터 구조 직접 관리
  - 클래스, 함수 등 심화 학습
- 녹화 / 재생 기능
- 점수 관리 기능

### 8. 8마디 작곡
- 객체지향 / 함수형 프로그래밍 응용
  - 재사용성이 높은 코드 작성
- 작곡 규칙에 따른 음악 자동 생성
  - 알고리즘에 따른 음악 코드 진행
  - 한 박자 안의 리듬 설정 가능
- 녹화 / 재생 기능

### 9. HW 자동 생성
- 입력: HW 생성에 필요한 정보
  - 32비트 adder라면 32라는 비트 수가 입력
- 출력: 해당 기능을 수행하는, 합성 가능한 게이트 레벨 Verilog
  - 32비트 adder에 대한 Verilog 파일

### 10. 게이트 레벨 시뮬레이터 제작
- 딜레이가 있는 AND, OR, NOT, XOR, flip-flop 등의 게이트를 파이썬 프로그램으로 작성
- 작성한 게이트로 회로를 구성하고 입력 신호를 준다
- 시간에 따른 게이트의 디지털 출력 신호를 시뮬레이션하고 텍스트로 출력하는 프로그램 제작
- 동작 결과는 waveform을 GUI로 보여주는 프로그램으로 확인

### 11. Parametric tree
- 파이썬 기반 객체지향 프로그래밍과 재귀 함수 실습
- 3D 그래픽 라이브러리 습득
- 3D 그래픽 관련 선형대수와 quaternion

## 3부. 바이브코딩 단원 (5기 신설, 잠정)

2026-10-14에 사용자가 방향을 정했다. 세부 내용은 부장님과 상의해 확정한다.

**정해진 방향**
- **도구와 무관한 원칙 중심**으로 짠다. 특정 도구의 사용법이 아니라 어떤 AI를 쓰든 통하는 방법을 가르친다
- 사내에서 쓸 수 있는 도구: **opencode**(지금 사용 가능), **Claude**(곧 열릴 예정). Claude Design은 쓸 수 있을지 알 수 없다
- 그래서 **디자인은 참고 수준**으로만 다룬다

전제: 이 단원은 1·2부 뒤에 온다. 고급 개념과 아키텍처를 배운 사람이라야 AI가 짠 코드를 판단할 수 있기 때문이다.

### 단원 구성
| # | 단원 | 배우는 것 | 왜 필요한가 |
|---|---|---|---|
| 1 | 만들 것을 정하기 (기획) | AI와 질문·답으로 기획하기. 누가 왜 쓰는지, 꼭 필요한 기능과 뺄 기능, 화면 흐름을 글로 정리하기 | 무엇을 만들지 흐릿하면 AI도 흐릿하게 만든다 |
| 2 | AI에게 제대로 시키기 | 큰 일을 작은 단계로 쪼개기, 맥락과 제약 주기, "이게 되면 완료"를 먼저 적기, 프로젝트 맥락 파일 쓰기 | "같은 AI를 쓰는데 왜 내 결과물만 다르지?"에 대한 답 |
| 3 | AI가 짠 코드 읽고 검증하기 | 받은 코드를 읽는 순서, 의심해야 할 신호, 테스트를 먼저 쓰게 하기, "거의 맞지만 틀린" 코드 찾기 연습 | 교육의 핵심인 "판단하는 눈" |
| 4 | 막혔을 때 빠져나오기 | 에러를 붙여넣기만 하지 않고 원인을 좁히는 법, 되돌리기(git), 처음부터 다시 시킬 때와 고쳐 쓸 때 | 같은 자리를 맴도는 반복에서 벗어난다 |
| 5 | 구조를 지키며 키우기 | 2부에서 배운 MVP 아키텍처와 디자인 패턴을 AI에게 요구하기, AI가 짠 코드 리팩터링 | 기능이 늘어도 고칠 수 있는 코드 |
| 6 | 회사에서 안전하게 쓰기 | 사내에서 쓸 수 있는 도구(opencode, 곧 Claude), AI에 넣으면 안 되는 정보, 사내망 환경의 제약 | 보안 사고 없이 쓴다 |
| 참고 | 화면 디자인 맛보기 | 디자인 도구로 시안을 받고 비교해 고르는 흐름을 **참고로만** 보여준다. 실습은 하지 않는다 | 사내에서 디자인 도구를 쓸 수 있을지 알 수 없다 |

핵심은 3번과 5번이다. 1·2부에서 배운 고급 개념과 아키텍처가 "AI의 코드를 판단하고 구조를 요구하는 힘"으로 이어지는 다리이고, 유튜브의 도구 사용법 강의와 SWAN이 갈리는 지점이다.

### 실습 (제안)
- **틀린 곳 찾기**: 강사가 일부러 버그를 심은 "AI가 짠 코드"를 받아 고친다. 사이트 수준 테스트의 마지막 문제와 같은 형식이다
- **손으로 짠 것 vs AI와 짠 것**: 2부에서 직접 만든 프로젝트 하나(예: 2048)를 AI와 다시 만들어 비교한다. 어디가 빨라졌고 어디서 구조가 무너졌는지 본다
- **내 업무 툴 만들기 (졸업 과제)**: 자기 부서의 반복 업무 하나를 골라 기획 → 구현 → 발표. 결과물은 사이트의 **완성작 갤러리**에 올린다

### 업무에서 쓸모 있는 주제 (골라 넣을 후보)
- 엑셀·CSV·로그 파일을 읽어 정리하고 보고서를 만드는 자동화
- 여러 사람이 쓰는 작은 웹 툴 만들기 (화면이 있는 사내 도구)
- 데이터를 그래프로 보여주는 대시보드
- 기존 스크립트를 AI와 함께 읽고 고치기 (물려받은 코드 다루기)
- 만든 툴을 동료에게 넘기기: 사용법 문서, 설치 방법

## 사이트에 보여줄 때의 묶음 (Claude 제안, 확인 전)

### 배우는 흐름 4단계
| 단계 | 내용 | 한 줄 |
|---|---|---|
| ① 다지기 | 환경 구성, 함수 활용법 | 내 PC에 개발 환경을 직접 세우고, 함수를 제대로 쓴다 |
| ② 깊어지기 | 파이썬 고급 개념, 알고리즘 기초(재귀), 객체지향과 디자인 패턴 | 코드를 읽는 눈과 구조를 잡는 힘을 기른다 |
| ③ 만들기 | 실습 프로젝트 | 배운 것을 써서 돌아가는 프로그램을 만든다 |
| ④ AI와 함께 만들기 (5기 신설) | 바이브코딩 단원 | AI에게 제대로 시키고, AI가 짠 코드를 판단한다 |

|---|---|---|
| 재귀와 파싱 | Equation parser, Parametric tree | 복잡한 문제를 작은 문제로 쪼개기 |
| 탐색 알고리즘 | 미로찾기 solver, Eight puzzle solver | 데이터 구조를 짜고 최적의 답 찾기 |

| 우리 업무와 닿는 과제 | HW 자동 생성(Verilog), 게이트 레벨 시뮬레이터 | 반도체 설계 업무에 바로 닿는 SW |
