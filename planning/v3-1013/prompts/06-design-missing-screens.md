## 프롬프트

방향 A "개발자의 노트" 디자인 기준 그대로, 수준 테스트에서 빠진 화면을 만들어 줘. 기존 `3a-3 보기 고르기`, `3a-4 마지막 문제`, `3a-5 결과` 화면과 같은 틀을 써 줘: 위쪽은 로고 + "수준 테스트" + 진행 표시 + [나가기], 가운데는 문제, 아래는 [← 이전] [다음]. 정보를 읽는 화면이니 장식은 덜고, 코드는 JetBrains Mono에 줄 번호를 붙여. 노랑은 쓰지 마. 1440 PC 화면이야.

### 1. 5번 주관식 (두 가지 상태)
- 진행 표시 **5 / 6**
- 질문: "다음 코드를 실행하면 무엇이 출력될까요? 출력되는 그대로 적어 주세요."
- 코드 (줄 번호 1~7):
```python
def f(n):
    if n == 0:
        return ""
    return f(n - 1) + str(n)

print(f(4))
```
- 코드 아래 입력 칸 하나. 한 줄짜리, 고정폭 글꼴, 앞에 `>>>` 또는 `출력:` 표시. 작은 도움말 "따옴표나 공백은 신경 쓰지 않아도 돼요"
- **상태 ① 비어 있음**: 입력 칸이 비어 있고 [다음]은 쓸 수 없는 모양
- **상태 ② 입력함**: 입력 칸에 `1234`, 입력 중 표시(ink 테두리 + sky 3px 바깥선), [다음]이 켜짐
- 정답이나 오답은 이 화면에서 알려 주지 않는다 (결과 화면에서 한꺼번에)

### 2. 6번 문제를 확정한 내용으로 다시 (세 가지 상태)
기존 `3a-4 마지막 문제`의 틀은 유지하고 내용만 바꿔 줘.
- 진행 표시 **6 / 6**
- 제목: "AI가 고친 코드입니다. 결과를 틀리게 만드는 줄을 찾아보세요."
- 위에서 아래로:
  1. 상황: "설비 로그에서 평균 온도를 구하는 코드를 돌렸더니 에러가 났어요. 에러를 AI에게 붙여넣고 고쳐 달라고 했더니, 아래처럼 고쳤습니다. **이제 에러 없이 숫자가 나옵니다.**"
  2. 원래 에러 (빨간 바탕 아닌, 터미널처럼 보이는 작은 상자): `ValueError: could not convert string to float: 'N/A'`
  3. 로그 파일 (작은 상자, 여섯 줄): `temp` / `80` / `82` / `N/A` / `78` / `-`
  4. AI가 고친 코드 (줄 번호 1~13, 줄마다 누를 수 있음):
```python
import csv

def average_temp(path):
    total = 0
    count = 0
    with open(path, encoding="utf-8") as f:
        for row in csv.DictReader(f):
            try:
                total += float(row["temp"])
            except Exception:
                pass
            count += 1
    return total / count
```
  5. 아래 안내: "줄을 눌러 한 줄을 골라 주세요" + 고른 줄 표시("고른 줄: 12") + [결과 보기]
- **상태 ① 아무것도 고르지 않음**: [결과 보기]는 쓸 수 없는 모양
- **상태 ② 마우스를 올림**: 9번 줄 위에 마우스, 그 줄이 옅은 sky로 칠해짐
- **상태 ③ 고름**: 12번 줄 `count += 1`을 고른 상태. 줄 전체가 sky 바탕 + 왼쪽에 ink 굵은 막대, "고른 줄: 12", [결과 보기]가 켜짐

### 3. 6번 해설 (한 화면 + 맨 위 상자만 다른 세 가지)
결과 카드 뒷면의 "문제별 해설" 목록에서 6번을 누르면 열리는 해설 화면이야. 결과 화면 위에 큰 창으로 띄우거나 한 화면으로 보여 줘. 읽는 글 폭은 980 이하.
- 맨 위: "6번 해설" + 제목 "에러를 고쳐 달라고 했더니, 에러를 숨겼다" + [← 결과로]
- **내 답 상자** (세 가지를 나란히 보여 줘):
  - 정답: "12번 줄 `count += 1`을 골랐어요. 정답이에요." (success 색)
  - 절반: "10번 줄 `except Exception:`을 골랐어요. 절반 맞았어요. 더 직접적인 원인이 있어요." (warning 색)
  - 오답: "9번 줄을 골랐어요. 정답은 12번 줄이에요." (error 색)
- **코드에 표시**: 같은 13줄 코드에서 정답 줄(12)은 success 바탕 + "결과를 틀리게 만드는 줄", 10~11줄(`except Exception:` / `pass`)은 warning 바탕 + "에러를 통째로 숨기는 줄", 내가 고른 줄은 왼쪽에 ink 막대로 표시. 줄 옆 여백에 `//` 주석처럼 짧은 설명을 단다
- **실제로 돌린 결과** 표:

| 경우 | 나와야 할 값 | 이 코드의 값 |
|---|---|---|
| 위 로그 (숫자 80, 82, 78) | 80.0 | **48.0** (240 ÷ 5칸) |
| 열 이름이 `temp`에서 `Temp`로 바뀐 로그 | 에러로 알려 줘야 함 | **0.0** (에러 없이) |

  "48.0"과 "0.0"은 큰 숫자 글꼴로 크게
- **숨은 문제 두 가지** (번호 목록):
  1. `count += 1`이 `try` 밖에 있어서, 숫자로 바꾸지 못하고 건너뛴 칸도 개수에 셉니다. 평균이 80이 아니라 48이 나와요. 경고 기준이 75도라면 실제로는 넘었는데도 경고가 울리지 않습니다.
  2. `except Exception: pass`는 모든 에러를 조용히 삼킵니다. 열 이름이 바뀌어 `temp` 열이 없어져도 에러 없이 0을 돌려줘요. 툴이 망가졌는데 아무도 모르게 됩니다.
- **한 줄 요약** (형광펜): "AI에게 '에러를 고쳐 줘'라고 하면, AI는 에러가 **안 나게** 만듭니다. **맞게** 만드는 것과는 다른 일이에요."
- **더 나은 코드** (원래 코드와 좌우로 나란히, 바뀐 줄만 sky 바탕):
```python
def average_temp(path):
    values = []
    with open(path, encoding="utf-8") as f:
        for row in csv.DictReader(f):
            v = row["temp"].strip()
            if v in ("", "N/A", "-"):   # 빈 값으로 정한 것만 건너뛴다
                continue
            values.append(float(v))      # 그 밖의 이상한 값은 에러로 알린다
    return sum(values) / len(values)
```
  아래 한 줄: "이 코드는 위 로그에서 80.0을 내고, 열 이름이 바뀌면 KeyError로 바로 알려 줍니다."
- **강사 한마디** (맨 아래, 첨부한 강사 백조 그림을 왼쪽에 작게): "에러가 사라졌다고 문제가 사라진 건 아닙니다. AI가 고친 코드가 '돌아가는지'가 아니라 '맞는지'를 보는 눈, SWAN에서 기릅니다." + 작은 글씨 "이 내용은 'AI와 함께 만들기' 단원의 'AI가 짠 코드 읽고 검증하기'에서 다룹니다"
- 맨 아래 버튼: [결과로 돌아가기] (보조) / [신청하기] (주)
