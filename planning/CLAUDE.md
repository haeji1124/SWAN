# SWAN 홍보 웹사이트

코딩이 처음인 현업 사람들에게 파이썬을 가르쳐, 자기 업무 자동화 하나는 직접 만들어 돌아가게 하는 사내 교육 **SWAN**(SW Academy for Newbie). 이 교육과 이를 운영하는 **Design Technology팀 IPS 파트**를 사업부에 알리는 사내망 원페이지 웹사이트.

## 누구를 위한 사이트인가
- **수강 희망자** (30~40대 엑셀 중심 현업): 메일 링크로 들어와 커리큘럼·쇼케이스를 보고 "나도 되겠다"를 느낀다 — 핵심 행동: 끝까지 스크롤, 5기 신청
- **실무진 요청자**: 부서장님께 공식 요청하기 애매한 작은 불편을 가볍게 남긴다 — 핵심 행동: 아이디어 남기기, 👍 공감
- **졸업생** (1~4기): 결과물 자랑, 토이프로젝트 모집 — 2단계
- **관리자** (나 + 부서장님): 신청자 선발, 아이디어 처리 — 2단계

## 핵심 루프
메일 링크 클릭 → **첫 5초 인트로에 꽂힘** → 스크롤하며 SWAN·IPS 파트 이해 → 다음 행동 하나(신청 / 아이디어 / 쇼케이스)
우선순위: **홍보 > 수강신청**. 모든 판단은 "첫 방문 한 번에 끝까지 보게 만드는가"로 한다.

## 범위
- 이번에 만든다: 원페이지 9섹션, 백조 마스코트 연출(인트로 → 소개 카드 → IPS 파트 → 마지막 CTA), 키네틱 타이포, 아이디어 보드 UI(로컬 상태)
- 목업으로 처리: 모든 데이터(`src/data/*.ts` 예시), [5기 신청]·[아이디어 남기기] 제출(안내 모달 / 로컬 상태)
- 만들지 않는다(2단계 이후): SSO 로그인, 서버 저장, 관리자 화면, 수강신청 선발 기능

## 기술
- React + Vite + TypeScript + Tailwind CSS v4
- 애니메이션: GSAP + ScrollTrigger (`@gsap/react`의 `useGSAP`), 부드러운 스크롤: Lenis (ScrollTrigger와 연동)
- **사내망(폐쇄망) 정적 배포**: 외부 CDN 금지. 폰트는 `@fontsource/*`로 번들, `vite.config.ts`에 `base: './'`
- 에셋: `public/assets/` — `intro.mp4`, `first.webp`(포스터), `poster.webp`(마지막 프레임), `plate.webp`(캐릭터 없는 배경), `fold/00~48.webp`(날개 접기 프레임, 911×490 투명, 영상 좌표 x194 y75), `mascot.webp`(접은 캐릭터 단독)
- 인트로 연출 기준 구현: `../swan-intro-demo.zip`의 `swan-intro.html` (좌표·타이밍은 이 파일이 정답)

## 디자인 원칙
- 무드: **달빛 호수의 밤** — 고요함, 프리미엄, 따뜻한 금빛 안개
- 색 토큰: night `#0b1424` / deep `#13213a` / mist `#c9d6ea` / moon `#f3ead2` / glow `#7fe3e6` / amber `#e8b36a` / line `rgba(201,214,234,.16)`
- 폰트: 제목 Gowun Batang · 본문 IBM Plex Sans KR · 라벨/코드 JetBrains Mono
- 히어로: 메인 "처음이어도, 우아하게." + 서브 "3개월 뒤, 매일 하던 반복 업무가 Python으로 가벼워집니다." / 슬로건: "물 위에선 우아하게, 물 밑에선 열심히 코딩하기". 호수·백조 세계관으로 일관되게
- 레퍼런스: soijeong.com — 섹션을 넘나드는 마스코트, 화면보다 큰 키네틱 타이포, 섹션별 배경 전환
- UX: [5기 신청] 버튼은 인트로 이후 항상 보인다. 업무 중 짧게 보므로 스크롤만으로 핵심이 전달돼야 한다
- 하지 말 것: 외부 CDN, 우측 고정 팝업 배너, 과한 정보량, 모바일에서 마스코트가 콘텐츠를 가리는 비행, `prefers-reduced-motion` 무시

## 작업 방식
