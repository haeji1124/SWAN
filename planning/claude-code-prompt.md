## Phase 0. 프로젝트 셋업

`SWAN/web/` 폴더에 React + Vite + TypeScript 프로젝트를 만들어 줘. CLAUDE.md를 먼저 읽어.

- 패키지: `tailwindcss` + `@tailwindcss/vite`(v4), `gsap`, `@gsap/react`, `lenis`, `@fontsource/gowun-batang`, `@fontsource/ibm-plex-sans-kr`, `@fontsource/jetbrains-mono`
- `vite.config.ts`: tailwind 플러그인, `base: './'` (사내 웹서버 하위 경로 배포 대비)
- **외부 CDN 금지**: 폰트는 `main.tsx`에서 fontsource import. Google Fonts 링크 쓰지 말 것
- 디자인 토큰: `src/index.css`의 Tailwind `@theme`에 색(night, deep, mist, moon, glow, amber, line)과 폰트(display, body, mono) 정의. `html`은 `color-scheme: dark`, 배경 night
- 에셋: `../swan-intro-demo.zip`을 풀어서 `assets/` 내용을 `public/assets/`로 복사 (`intro.mp4`, `first.webp`, `poster.webp`, `plate.webp`, `fold/00~48.webp`). 그리고 `fold/48.webp`의 투명 영역을 잘라낸 `mascot.webp`를 만들어 줘
- 부드러운 스크롤: `src/lib/smooth.ts`에 Lenis를 만들고 GSAP ticker·ScrollTrigger와 연동. `prefers-reduced-motion`이면 Lenis를 끈다
- 섹션 컴포넌트 빈 껍데기(제목만), 위→아래 순서:
  `Nav` · `Intro` · `Stats` · `Curriculum` · `Showcase` · `Team`(IPS 파트) · `IdeaBoard` · `ToyProjects` · `Finale`(CTA+푸터)
- 예시 데이터 `src/data/`(모두 "예시" 주석):
  - `stats.ts`: 기수 4, 졸업생 36, 만든 자동화 40, 과정 3개월
  - `curriculum.ts`: 4단계 — ①1~2주 "물에 발 담그기"(사내 환경 세팅, 파이썬 기초, AI 코딩 도우미) ②3~5주 "데이터와 친해지기"(엑셀·CSV, pandas, 파일 자동화) ③6~8주 "자동화 날개 달기"(보고서 자동 생성, 메일·웹 자동화, 예약 실행) ④9~12주 "내 업무로 날아오르기"(개인 프로젝트, 멘토링, 데모데이). 주 2~3회 · 회당 2시간 · 오프라인
  - `showcase.ts`: 졸업생 결과물 6개 (제목, 기수, 직무, Before→After 시간, 태그). 빈 배열이면 빈 상태 카드가 나오게 설계

## Phase 1. 인트로: 영상 → 캐릭터 분리 → 소개 카드 착지

이 사이트의 첫 5초를 만든다. 사용자는 **업무 중 사내 메일 링크를 눌러 들어온 사람**이고, 여기서 흥미를 못 느끼면 바로 닫는다.

`Intro` 컴포넌트를 GSAP ScrollTrigger로 만들어 줘. `../swan-intro-demo.zip`의 `swan-intro.html`은 동작이 검증된 프로토타입이다. **연출 타이밍과 좌표 계산은 이 파일을 그대로 따른다.**

### 에셋 (public/assets)
- `intro.mp4`: 1280×720. 물 위의 백조가 변신해 날개를 펴고 떠오른다. 마지막 프레임에서 날개를 편 채 떠 있다
- `first.webp`: 영상 첫 프레임(poster) / `poster.webp`: 마지막 프레임(대체 이미지)
- `plate.webp`: 캐릭터가 없는 마지막 프레임 배경
- `fold/00~48.webp`: 날개를 접는 프레임 49장. 911×490 투명 webp이고, 영상 좌표 (194, 75)에 놓으면 영상 속 캐릭터와 정확히 겹친다
  - 몸통 영역(캔버스 기준): 중심 (437, 247), 크기 415×475

### 구조
1. 인트로 섹션 높이 340vh, 안쪽에 100svh sticky 무대
2. 무대에 전체화면 영상 (object-fit: cover, muted, playsInline, autoplay, loop 없음)
3. 영상이 끝나면 마지막 프레임에서 멈추고 제목과 "SCROLL ↓" 힌트를 페이드인
   - eyebrow: `SW Academy for Newbie` / 제목: **처음이어도, 우아하게.** / 서브카피: **3개월 뒤, 매일 하던 반복 업무가 Python으로 가벼워집니다.** (제목보다 0.3초 늦게 페이드인)
4. 무대 하단에 카드 패널. 패널 안 소개 카드에 캐릭터가 앉을 빈 슬롯(div) 배치
   - 패널 제목: `SWAN · 5기 모집` / **물 위에선 우아하게, 물 밑에선 열심히 코딩하기**
   - 소개 카드: "안녕, 나는 SWAN이야" + 3개월 과정 한 줄 설명 + 코드 예시 `$ python merge_reports.py ./팀별실적` / `✓ 5개 팀 실적 취합 완료 (1시간 30분 → 4초)`
   - 걱정 해소 칩 3개: "환경 세팅부터 같이" / "결과물 부담 없이" / "AI 활용법까지"
5. 캐릭터 레이어: `<canvas width=911 height=490>`에 fold 프레임을 그린다 (프레임 49장 미리 로드)

### 스크롤 타임라인 (인트로 진행률 p = 0~1)
- 0.00~0.12: 영상 위에 캐릭터 캔버스를 영상과 같은 위치로 겹쳐 표시(0.002~0.03 페이드인). 영상을 `plate.webp`로 크로스페이드(0.01~0.12). 제목·힌트는 0~0.08에 사라짐
- 0.02~0.45: 배경이 점점 어둡고 흐려짐 (brightness 0.45, blur 8px, saturate 0.7) + 가장자리 비네트
- 0.05~0.40: **날개 접기** — 진행률에 맞춰 fold 프레임 0→48을 캔버스에 그림
- 0.36~0.50: 몸통이 6% 커졌다 돌아오고(몸통 중심 기준) drop-shadow가 생기며 스티커처럼 떼어지는 느낌
- 0.30~0.68: 카드 패널이 아래에서 위로 슬라이드 업 (translateY 105% → 0)
- 0.44~0.92: 캐릭터가 포물선(위로 최대 `min(화면높이×0.12, 90px)`)을 그리며 슬롯 중앙으로 이동하고 슬롯 크기에 맞게 축소(몸통 기준 92%). 이동 중 최대 -8도 기울어짐
- 0.90 이후: 슬롯을 "채워짐" 상태로 (점선 → 실선, 라벨 숨김)

### 좌표 계산 (중요)
- object-fit: cover 배율 `s = max(화면폭/1280, 화면높이/720)`, offset `((화면폭-1280s)/2, (화면높이-720s)/2)`로 캐릭터 캔버스를 영상과 픽셀 단위로 일치시킨다
- 목표 위치는 **매 프레임** 슬롯의 `getBoundingClientRect()`(무대 기준 좌표로 변환)로 계산해, 리사이즈와 모바일에서도 정확히 슬롯에 안착하게 한다
- 리사이즈 시 `ScrollTrigger.refresh()`

### 예외 처리
- 영상이 끝나기 전에 스크롤하면 바로 마지막 프레임으로 이동하고 끝난 상태로 전환
- 자동재생이 막히거나 영상 로딩에 실패하면 `poster.webp`로 대체하고 끝난 상태로 전환
- `prefers-reduced-motion`이면 영상과 애니메이션 없이 캐릭터가 카드에 앉은 최종 상태만 표시 (인트로 높이도 100svh로)
- 모바일(세로 화면)에서 캐릭터가 화면 밖으로 잘리지 않을 것. 모바일에서 카드는 1열, 코드 예시는 숨김

### 수용 기준
- [ ] 영상이 끝나면 제목·SCROLL 힌트가 뜬다
- [ ] 스크롤을 시작할 때 영상 → 캐릭터 레이어로 바뀌는 순간이 **티 나지 않는다**
- [ ] 날개가 스크롤에 맞춰 접히고, 거꾸로 스크롤하면 다시 펴진다
- [ ] 1440×900, 390×844 모두에서 캐릭터가 슬롯 중앙에 정확히 안착한다
- [ ] 창 크기를 바꿔도 안착 위치가 맞다
- [ ] reduced-motion에서 최종 상태만 보인다

**확인**: 데스크톱·모바일 뷰포트에서 처음부터 끝까지 천천히, 빠르게, 거꾸로 스크롤해 본다.
다 되면 요약해 줘.

## Phase 2. 마스코트 공용화: 백조가 사이트를 안내한다

Phase 1에서 만든 "캐릭터를 슬롯으로 날려 보내는 계산"을 인트로 전용 코드에서 **공용 부품**으로 분리해 줘.

### 설계
- `src/mascot/MascotGuide.tsx`: 화면에 고정된(position: fixed) 마스코트 레이어 하나. fold 프레임 캔버스를 그대로 쓴다
- `src/mascot/stops.ts`: 정거장 목록. 각 정거장 = `{ slotId, start, end, frame(0~48), tilt, bob }`. 섹션은 `<MascotSlot id="team" />`만 놓으면 된다
- 정거장 사이 구간에서는 이전 슬롯 → 다음 슬롯으로 포물선 비행. 슬롯에 머무는 동안은 위아래로 살짝 둥실(bob ±4px, 2.4초 주기)
- 인트로의 날개 접기·떼어짐 연출은 그대로 유지(인트로 정거장의 특수 구간)

### 1차 정거장 3곳
1. **intro** → SWAN 소개 카드 슬롯 (Phase 1 그대로)
2. **team** → IPS 파트 소개 카드 슬롯. 도착하면 말풍선: "필요한 툴, 우리가 만들어 드려요"
3. **finale** → 마지막 CTA. 슬롯에 도착한 뒤 스크롤을 더 내리면 **날개 접기 프레임을 거꾸로(48→0) 재생**해 날개를 펴고 위로 날아오르며 사라진다

### 규칙
- 슬롯이 화면에 없는 구간(정거장 사이 긴 콘텐츠)에서는 마스코트를 화면 가장자리 작은 크기로 두거나 숨긴다. **콘텐츠를 가리지 말 것**
- 모바일(<768px): 비행 없이 각 슬롯 안에 `mascot.webp`가 정적으로 앉아 있다 (인트로만 예외)
- reduced-motion: 모든 슬롯에 정적 이미지

### 수용 기준
- [ ] 인트로 → IPS 파트 → 마지막 CTA로 백조가 끊김 없이 이어서 이동한다
- [ ] 정거장을 하나 추가할 때 `stops.ts` 한 줄 + `<MascotSlot>` 하나면 된다
- [ ] 마지막 CTA에서 날개를 펴고 날아오른다. 거꾸로 스크롤하면 되돌아온다
- [ ] 모바일에서 마스코트가 본문을 가리지 않는다

**확인**: 1440×900에서 처음부터 끝까지 스크롤. 390×844에서 각 카드에 백조가 앉아 있는지.
다 되면 요약해 줘.

## Phase 3. 나머지 섹션 + 키네틱 타이포 + 배경 전환

레퍼런스는 soijeong.com의 역동성이다. 화면보다 큰 글자가 흐르고, 섹션이 바뀔 때 장면이 바뀌는 느낌을 준다. 데이터는 `src/data/`의 예시를 쓴다.

### 공통
- **섹션 배경 전환**: 호수의 시간대처럼 바뀐다 — 인트로·성과·커리큘럼: 달밤(night) → 쇼케이스: 새벽 푸른 안개 → IPS 파트·아이디어: 금빛 안개(amber 그라디언트) → 마지막 CTA: 다시 달밤 + 큰 달 글로우. ScrollTrigger로 body 배경색을 보간
- **키네틱 타이포 띠**: 섹션 사이에 화면 폭보다 큰 문구가 스크롤에 맞춰 가로로 흐른다(좌·우 반대 방향 2줄). 예: `Python for Newbie · 처음이어도, 우아하게 ·` / `물 밑에선 열심히 · Automate the boring stuff ·`
- 섹션 진입 시 요소가 아래에서 페이드업 (ScrollTrigger.batch)
- 주요 버튼: moon 색 알약형 / 보조: glow 외곽선

### 섹션별
1. **Nav**: 인트로가 끝나면 등장. SWAN 로고(백조 머리 + 글자), 섹션 바로가기, 우측 **[5기 신청]** 고정. 스크롤 시 반투명 블러
2. **Stats**: 숫자 4개 카운트업(화면 진입 시 1회). 라벨 아래 작은 설명. "예시 수치" 표시는 개발 중에만
3. **Curriculum**: 섹션을 핀 고정하고 스크롤에 따라 세로 진행선이 차오르며 4단계가 하나씩 활성화. 각 단계: 주차, 이름, 배우는 것 3개, "이 단계가 끝나면 할 수 있는 것" 한 줄. 상단에 "주 2~3회 · 회당 2시간 · 오프라인 · 3개월"
4. **Showcase**: 데스크톱은 핀 고정 + 가로 스크롤 갤러리, 모바일은 가로 스와이프. 카드: 직무·기수 배지, 제목, **Before → After 시간**(예: 1시간 30분 → 4초), 태그. 데이터가 비면 "곧 졸업생들의 작품이 걸립니다" 빈 상태 카드
5. **Team (IPS 파트)**: "Design Technology팀 IPS 파트 — 현업에 필요한 웹과 툴을 만듭니다". 하는 일 키워드가 흐르는 태그 마키(업무 자동화 · 사내 웹 시스템 · 데이터 대시보드 · 데이터 수집 · 보고서 자동화 · SWAN 교육). 마스코트 슬롯이 있는 소개 카드. CTA: "아이디어 보드에 남기기 →"
6. **IdeaBoard**: "부서장님께 말하긴 애매한 작은 불편, 여기 던져 주세요". 공개 아이디어 카드(포스트잇처럼 살짝 기울어진 더미) + 상태 배지 + **[👍 나도 필요해요]** 토글(로컬 상태, 누르면 튀어 오르는 반응). [아이디어 남기기] → 모달(제목, 설명, 공개 여부 토글) → 제출하면 로컬 목록 맨 앞에 추가 + "접수됐어요" 토스트. 모달에 "2단계에서 사내 SSO로 실명 연동 예정" 안내는 넣지 말고 코드 주석으로만
7. **ToyProjects**: 졸업생 모집 중 프로젝트 카드 3개 (리더 기수, 모집 인원 진행 막대, 기술 태그). "졸업생 전용" 배지
8. **Finale + 푸터**: 큰 달 글로우 위에 "다음 호수에서 만나요 — SWAN 5기" + [5기 신청] / [아이디어 남기기]. 마스코트가 날아오르는 정거장. 푸터: Design Technology팀 IPS 파트 · 문의처(예시)

## Phase 4. 다듬기 — 부서장님께 보여줄 수 있는 상태로

- **모바일 390×844**: 모든 섹션 레이아웃, 핀 고정 구간이 너무 길지 않은지, 가로 스크롤이 페이지 전체를 밀지 않는지(가로 넘침 없음)
- **reduced-motion**: Lenis 끔, 핀·비행·카운트업 없이 최종 상태
- **성능**: fold 프레임 49장 미리 로드 + 디코드, 영상 preload, 이미지 `loading="lazy"`(인트로 제외), 스크롤 중 레이아웃 계산 최소화(getBoundingClientRect는 rAF 안에서만), 60fps 유지
- **접근성**: 모든 버튼에 라벨, 영상·장식 이미지 `aria-hidden`, 마스코트 슬롯에 `role="img"` + 설명, 텍스트 대비 4.5:1 이상, 키보드로 모달 열고 닫기(ESC), 포커스 링(glow)
- **사내망 빌드**: `npm run build` 결과 `dist/`를 하위 경로에서 열어도 에셋이 깨지지 않는지(`base: './'`), 외부 도메인 요청 0건
- 탭 제목 `SWAN · SW Academy for Newbie`, 파비콘 = 백조 머리

**확인**: `npm run build && npm run preview`로 데스크톱·모바일 각각 전체 스크롤. 개발자도구 Performance에서 스크롤 중 끊김 확인.
다 되면 남은 이슈와 함께 요약해 줘.
